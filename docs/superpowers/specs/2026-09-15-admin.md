# Excel administration scope

Approved: proceed from the Excel audit. Latest user correction: remove Overall Ranking and Popularity. Only followers/views metrics remain; no invented combined scores.

Implementation decisions: username/password login backed by D1 users, manager/staff roles. Manager controls users, categories, settings and ranking publication. Staff can manage VTubers and snapshots, view rankings, generate/read reports. Both can view their profile/change their own password. Audit logs are manager-only. Users have active/inactive status. Disable rather than hard-delete domain data. Public UI keeps light/dark/system themes.

First manager is created through a one-time setup token stored as a Cloudflare secret; no default credentials from Excel. User enters their password themselves. Session cookies are Secure/HttpOnly/SameSite=Strict, hashed server-side, expire after 8h; mutation requests require exact same Origin and CSRF token. Credential changes revoke sessions. Login is throttled per IP and account. All admin endpoints enforce authentication server-side.

Extend existing D1 tables without replacing data. Preserve numeric internal IDs; expose prefixed IDs where useful. Vtuber fields include country, debut_date, banner_url, youtube_url, twitch_url, x_url, description/bio and video_count snapshots. Categories are the two built-in metrics; managers edit labels/order/status, not arbitrary score formulas.

Rankings calculate from latest snapshot at or before the end of a selected Bangkok calendar month, or latest overall. Score is followers or total_views. Ties use competition ranks (1,1,3), stable VTuber ID order. Rank change compares previous calendar month (or previously saved alltime batch). Recalculate replaces exactly one period/category batch atomically; audit inserted in same transaction. Inactive channels are excluded from public results. Reports persist a JSON snapshot and offer CSV download; do not silently change when rankings later change. Settings support site_name, site_status active/maintenance, current_ranking_period YYYY-MM, ranking_update_frequency manual/monthly. Frequency describes intended cadence; no claim of scheduled syncing until a scheduler exists.

No external YouTube fetching credentials or data pipeline is supplied; snapshots are entered by admins. No Excel credential import. Deployment uses existing Pages/D1; local tests and isolated D1 fixtures precede production migration. Back up D1 before additive migrations.
