# Cypress E2E Implementation Plan

**Goal:** มี Cypress E2E ที่รันได้จริงสำหรับ public journey (ดูอันดับ, ค้นหา) และ admin journey (login, จัดการช่อง) โดย stub API ด้วย `cy.intercept` ทั้งหมด ไม่พึ่ง production backend

**Architecture:** Cypress ziyaret dev server (`vite`, baseUrl `http://localhost:5173`) ทุก `/api/v1/*` ถูก stub ผ่าน fixtures + custom commands (`cy.loginAs`, `cy.stubPublicApi`) ไม่มี D1/YouTube/production dependency

**Tech Stack:** Node.js `^20.19.0 || >=22.12.0`, Cypress 15 (ESM config เพราะ `frontend/package.json` เป็น `"type": "module"`), Vite 8

**Spec:** `docs/PROJECT_STRUCTURE.md`

## Global Constraints

- ห้ามยิง production API หรือ production D1 จาก E2E — stub ทุก request ผ่าน `cy.intercept`
- Config ต้องเป็น ESM (`import`/`export default`) เพราะโปรเจกต์เป็น `"type": "module"`
- ไม่ commit `cypress/videos`, `cypress/screenshots`, `cypress/downloads`
- Tests ใช้ text/role selectors ไม่ผูกกับ CSS classes

### Task 1 Cypress foundation and public journeys

**Files:**
- Create: `frontend/cypress.config.js` (ESM)
- Create: `frontend/cypress/support/e2e.js`
- Create: `frontend/cypress/support/commands.js`
- Create: `frontend/cypress/fixtures/rankings.json`, `summary.json`, `vtubers.json`
- Create: `frontend/cypress/e2e/public/home.cy.js`, `search.cy.js`
- Modify: `frontend/package.json` (scripts `cypress:run`, `test:e2e`)
- Modify: `.gitignore` (cypress artifacts)

**Interfaces:**
- Consumes: dev server ที่ `http://localhost:5173`
- Produces: `npm run test:e2e` รัน headless ผ่านทุก spec

- [ ] **Step 1: Install Cypress and scaffold**

```powershell
npm install --save-dev cypress
```

Create ESM `cypress.config.js` (baseUrl, viewport, `video: false`, `screenshotOnRunFailure: false`, supportFile, specPattern), `support/e2e.js` (ResizeObserver guard + commands import), `.gitignore` entries, package scripts.

- [ ] **Step 2: Add fixtures and commands**

Fixtures ตรง response shape ของ public API (`rankings`, `summary`, `vtubers`). Commands:
- `cy.stubPublicApi()` — intercept `rankings`, `summary`, `vtubers` ด้วย fixtures
- ใช้ `beforeEach` + fresh `cy.visit()` ทุก test

- [ ] **Step 3: Write public journey specs**

`home.cy.js`: stub แล้ว visit `/` รอ `@getRankings` ตรวจชื่อเว็บ/อันดับจาก fixture, เปลี่ยน metric แล้วยิง intercept ใหม่
`search.cy.js`: visit `/search` พิมพ์คำค้น รอ `@searchQuery` ตรวจผลลัพธ์จาก fixture

- [ ] **Step 4: Start dev server and verify GREEN headless**

```powershell
npm run dev
npx cypress run
```

Expected: ทุก spec ผ่าน headless (Electron) โดยไม่ยิง network จริงนอกจาก dev server

### Task 2 Admin journey

**Files:**
- Create: `frontend/cypress/e2e/admin/login.cy.js`, `channels.cy.js`
- Modify: `frontend/cypress/support/commands.js` (เพิ่ม `cy.loginAs`)

**Interfaces:**
- Consumes: fixtures เดิม + auth/admin stubs
- Produces: admin specs ผ่าน headless

- [ ] **Step 1: Add the login command and specs**

`cy.loginAs(role)` stub `GET /api/v1/auth/me` → `{ user, csrfToken }` แล้ว visit `/admin` ตรวจ tab `จัดการช่อง`

`channels.cy.js`: login แล้ว stub `GET /api/v1/admin/vtubers` → เห็นชื่อช่องจาก stub; กดเพิ่มช่องเห็น dialog

- [ ] **Step 2: Run the complete verification set**

```powershell

```

Expected: ทุกคำสั่ง exit 0
