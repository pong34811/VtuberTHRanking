# Excel Admin Implementation Plan

**Goal:** Deliver the seven Excel management areas, excluding Overall/Popularity per user correction.
**Architecture:** React admin workspace + Hono modules + existing D1. Root owns auth/migrations/integration. Independent UI/domain tasks share the API contract below.
**Tech Stack:** React 19, Hono 4, D1, Node 24 tests, Cloudflare Pages Functions.

## Global constraints
- Preserve existing data and unrelated working changes. Do not stage or commit other work.
- No default/sample production passwords. Protect admin reads and writes server-side.
- Only followers/views rankings. No Overall Ranking or Popularity.
- Same minimalist responsive light/dark theme as public pages.

## Task 1: Schema/auth/integration (root)
- [ ] Add baseline and additive migrations, auth/session/rate-limit storage, all Excel domain fields.
- [ ] Implement setup/login/logout/me/password with secure hash and cookies, CSRF/origin checks and role guard.
- [ ] Integrate app modules and fix public API correctness; test auth against SQLite adapter and Workers runtime.

## Task 2: Domain API (delegate)
- [ ] Implement `frontend/server/admin.js` plus focused helpers, export default Hono router. Mount at /api/v1/admin after auth middleware. Root supplies c.get('user') {id,username,display_name,email,role,status}, c.env.DB, c.get('session').
- [ ] All lists return {results:[...]}; failures {message:string}. JSON mutation results {ok:true,id?}. Use numeric IDs.
- [ ] GET/POST /vtubers; PUT /vtubers/:id (full object). Fields name,slug,bio,avatar,agency_name,country,debut_date,banner_url,youtube_url,twitch_url,x_url,category (content),affiliation,is_active. Keep channel_url/platform for compatibility.
- [ ] GET /vtubers/:id/snapshots -> results; POST same path fields followers,total_views,video_count,recorded_at (ISO). Preserve avg_views default. All VTuber writes allowed to staff, audit atomically.
- [ ] GET /categories and PUT /categories/:id manager-only write. Fields id (followers/views),name,slug,description,sort_order,status.
- [ ] GET /rankings?period=monthly|alltime&month=YYYY-MM&category=followers|views; POST /rankings/calculate same body manager-only, latest eligible snapshots, ranks/ties/changes, atomic batch save+audit. Results rows include VTuber name and stored counts. Cap channel count to safe D1 batch limit with clear error rather than partial publish.
- [ ] GET /reports; POST /reports {period,month,category} persists current ranking snapshot + audit; GET /reports/:id/download CSV escaped against spreadsheet formulas, stored snapshot only. Both roles.
- [ ] GET /audit-logs manager only, capped latest 200.
- [ ] GET /settings; PUT /settings manager-only, body {site_name,site_status,current_ranking_period,ranking_update_frequency}; strict known keys/values, transactional audit.
- [ ] GET /users manager-only, public fields no hash; POST {username,display_name,email,role,status,password}; PUT /users/:id {display_name,email,role,status,password?}; cannot disable/demote self; sessions revoked on password/role/status changes. Root exports hashPassword(password), validatePassword(password) from ./password.js. Store last_login_at. Audit sanitized metadata only.
- [ ] Create meaningful domain tests where practical and report limits. Do not edit migrations/auth/main Functions file.

## Task 3: Admin UI (delegate)
- [ ] Own frontend/src/admin/**, App.jsx route and optional footer admin link. New AdminPage loaded lazily, /admin/* route. Do not edit public pages, API main client or global CSS; admin.css scoped.
- [ ] Auth API root /api/v1/auth: GET /me -> {user,csrfToken} or 401 {setupRequired:boolean,message}; POST /setup {setupToken,username,display_name,email,password}; POST /login {username,password}; both -> {user,csrfToken}. POST /logout, POST /password {currentPassword,newPassword}. All mutations except login/setup send X-CSRF-Token from me/login. Fetch credentials same-origin.
- [ ] Setup page shown only setupRequired; read no secret from localStorage. User manually enters setup code and credentials. Password inputs correctly labeled. Login failures visible. No demo credentials.
- [ ] Tabs: channels, rankings, categories, reports, users(manager), history(manager), settings(manager). Match domain routes Task 2 exactly. Staff can edit channels/snapshots and create reports; manager controls other writes. Reauth on 401. Implement clear loading/error/empty/success states, stable edit forms with validation, timestamps.
- [ ] Channel editor includes all Task 2 fields, active/inactive toggle, snapshot entry and list. Disable duplicate submissions, preserve input on validation errors.
- [ ] Rankings filters month/metric/period and manager recalculate action. Categories only followers/views editable metadata, no add Overall/Popularity. Reports list/create/download. Users create/edit/disable with role choices. Audit read-only; settings four fields; password change available to both roles.
- [ ] Build and report; root integration review follows.

## Task 4: Verification/deploy (root + independent review)
- [ ] Tests: setup once, unauthenticated denied, CSRF/origin denial, login throttling, staff forbidden manager endpoints, password/session invalidation, unique fields and invalid input, snapshots/calculate tie/month boundaries, report immutability, audit atomicity.
- [ ] Build and mobile/desktop browser checks; verify local setup/login/admin edits then production logged-out denial.
- [ ] Backup D1, apply migrations, set one-time setup secret without printing it, deploy production and provide protected setup instructions in ignored local file.

## Shared schema contract
Existing vtubers columns retained, add country TEXT default Thailand, debut_date TEXT default '', banner_url/youtube_url/twitch_url/x_url TEXT default ''. Existing stats_snapshots add video_count INTEGER default 0. Existing rankings add subscriber_count,total_views,video_count INTEGER defaults 0 and status TEXT default active. categories(id TEXT PK,name,slug UNIQUE,description,sort_order,status). users(id TEXT PK,username UNIQUE,password_hash,display_name,email UNIQUE,role,status,created_at,updated_at,last_login_at). sessions(token_hash TEXT PK,user_id TEXT,csrf_token TEXT,expires_at INTEGER,created_at INTEGER). auth_attempts(key TEXT PK,count INTEGER,window_start INTEGER). audit_logs(id TEXT PK,user_id TEXT,action,target_type,target_id TEXT,details TEXT,created_at TEXT default datetime now). reports(id TEXT PK,report_type,report_period,category_id,total_vtubers,generated_at TEXT default datetime now,generated_by TEXT,snapshot_json TEXT). settings(setting_key TEXT PK,setting_value TEXT,description TEXT,updated_at TEXT default datetime now). bootstrap_lock(id INTEGER PK CHECK id=1).
